# SurveyJS v3 × Vuetify Form Demo

Side-by-side comparison of SurveyJS Form Library v3 and a native Vuetify form inside a Vue 3 + Vuetify app.

SurveyJS styling uses an experimental CSS-variable bridge (`src/styles/vuetify-sjs-adapter.css`) because there is no official Vuetify theme adapter yet.

## Stack

- Vue 3
- Vuetify 4
- `survey-core` / `survey-vue3-ui` `3.0.0-beta.8`

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173/
